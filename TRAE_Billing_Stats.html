📖 Getting Started Tutorial

How to extract your TRAE billing data

1

Download Data Collector

First, download the script below. This Python application will securely fetch your data directly from the official TRAE API.

Requirement: Python 3.x + PyQt5 installed (`pip install PyQt5 requests`)
2

Inspect Network Request

Open TRAE Usage Settings in your browser and press F12.

Navigate to the "Network" tab and look for this specific API call:

https://api-us-east.trae.ai/trae/api/v1/pay/query_user_usage_group_by_session
3

Extract Credentials (Cookie & JWT)

Click on the request found in Step 2. In the "Headers" section, find and copy these two values:

  • Cookie (The all long string starting with _ga... or similar)
  • Authorization (The JWT token starting with Bearer ...)
4

Finalize Data Export

Paste the values into the Trae Usage App and click "Fetch All Pages". Save the resulting JSON file and upload it here!
